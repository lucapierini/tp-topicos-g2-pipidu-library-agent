# Reseña: Clean Code

**Autor:** Robert C. Martin
**Subtítulo:** A Handbook of Agile Software Craftsmanship
**Categoría:** Ciencias de la Computación
**Primera edición:** 2008 (Prentice Hall)

## Sinopsis

El libro sostiene que el código es una herramienta de comunicación entre personas y que escribir código limpio es una responsabilidad profesional. A partir de ejemplos reales de código mejorable, el autor muestra cómo refactorizarlo paso a paso para que sea legible y fácil de mantener.

## Temas principales

- **Nombres significativos** para variables, funciones y clases.
- **Funciones pequeñas** que hacen una sola cosa.
- **Comentarios**: preferir código que se explique solo; usar comentarios para lo que el código no puede decir.
- **Manejo de errores** con excepciones en lugar de códigos de retorno.
- **Pruebas unitarias** y desarrollo guiado por pruebas.
- **Olores de código (code smells)** y heurísticas para detectarlos.

## Valoración

Es una lectura muy difundida en cursos de ingeniería de software. Los ejemplos están en Java, pero los principios se aplican a otros lenguajes. Algunas recomendaciones son discutidas por su rigidez, por lo que conviene leerlas con criterio.

## Para quién es

Estudiantes avanzados y profesionales con experiencia básica en programación orientada a objetos.
